## 翻阅操作

| 操作 | 行为 |
| --- | --- |
| 顺时针旋转 | 看更旧一条，到最旧后停住 |
| 逆时针旋转 | 看更新一条，到最新后停住 |
| # | 重新只读扫描并刷新，不追加记录 |
| 0 | 返回主页 |
| A | 明确追加一条 `TEST PASS D:0` 诊断记录，并跳到最新 |
| B | 打开“追加130条TEST”确认页，# 执行、0 取消 |
| C | 查看有效数量、无效槽数、待写队列数和写入错误状态 |

页面第一行如 `LOG 002/006`，表示当前是第2新的记录，共6条；第二行 `ID:` 是事件编号；第三行包含 `NUM`、`DIAL`、`FING` 或 `TEST`、`PASS/FAIL` 和 `D:0/1`。`D:1` 仅用于数字或旋钮识别出的胁迫成功。

这是直接开放的模块测试入口，最终日志查看权限由管理员状态机控制。普通/胁迫认证成功页仍相同，只有主动查看诊断或日志才能看到内部标志。

## 掉电恢复与循环覆盖

先按 C 确认 `Pending:0 Err:0`，再断电重启，不整片擦除。进入 4，已提交日志的编号与内容应仍在。再做一次入口3的认证，最新编号应继续递增。

循环压力验证放在正常记录验证之后：在入口4按 **B**，确认页会提示旧页将轮换。按 **#** 明确追加130条标为 `TEST` 的记录，按 **0** 可取消且不写入。

批量操作会按已确认的策略淘汰最旧的新版记录；不会清除口令配置或旧格式日志。最大容量128条，每页64条，整页轮换后在完整无故障写入条件下保留65～128条，不会始终固定显示128。翻阅剩余记录应按编号连续排列，最新编号较批量前增加130。

测试数据均标为 TEST，不伪装成真实数字、旋钮或指纹认证。批量入口只属于本测试程序，正式状态机不应提供此写入入口。

## 模块与状态机接口

| 模块 | 职责 |
| --- | --- |
| `hardware/log.c/.h` | 新版二进制记录、CRC、提交核验、上电扫描、编号恢复、最旧页轮换和最近记录读取 |
| `hardware/audit.c/.h` | 从 Auth 取一次事件，放入4槽 RAM 队列，失败保留重试，成功才出队 |
| `user/log_demo.c/.h` | 旋钮翻阅、状态页、明确标记的诊断写入 |
| `user/duress_demo.c` | 实例化认证与审计适配，不操作舵机、蜂鸣器或指示灯 |

状态机使用约定：

1. 上电调用一次 `Audit_Init()`，只读恢复日志并初始化 RAM 队列。不要把它当作运行中的刷新接口，刷新使用 `Log_Init()`。
2. 完整输入交给 `Auth_Evaluate()`。正常和胁迫成功的可见反馈走同一路径。
3. 调用 `Audit_Capture(&auth, ...)`。它仅在队列有空间时消费 Auth 的一次性事件；队列满时事件仍留在 Auth 中，须在后续主循环重试。
4. 在主循环调用 `Audit_Process()`，每次最多尝试持久化一个事件。返回1才表示队头记录已提交并核验成功，失败不出队。
5. 用 `Audit_GetPendingCount()`、`Audit_HasWriteError()` 检查进度。Capture 成功表示进入队列，不等于已经写入 Flash；未写入的 RAM 事件在断电后无法恢复。正式开锁时如何处理持续存储故障，由之后状态机明确决策。
6. 读取使用 `Log_Read(0, &record)` 获取最新，索引递增表示更旧。`Log_GetCount()` 返回有效记录数，`Log_GetInvalidCount()` 返回扫描跳过的非空坏槽数。

不要同时对同一事件调用 `Auth_TakeAudit` 和 `Audit_Capture`。兼容的 `Log_Write(method,result)` 仍保留；新代码优先使用审计队列或 `Log_WriteEvent(method,result,duress)`。

## 格式、存储与故障处理

每条16字节，包含提交标记、格式版本、32位序号、方式、成败/胁迫标志、CRC与保留字段。先写并回读有效载荷，最后写提交标记。控制器即使在提交后报错，只要实际记录完整核验通过，就视为写入成功，避免重试重复记录。

上电扫描不擦写。CRC错误、半写入记录单独跳过；新追加会避开被占用的坏槽。当前页满时只处理另一页，保留含最新记录的当前页；只有需要覆盖旧页时才擦除，空白页直接使用。编号从最新有效记录恢复，支持32位自然回绕；全部记录丢失或整片擦除后只能重新从1开始。

| 地址范围 | 用途 |
| --- | --- |
| `0x08000000`～`0x0800DBFF` | 程序区，构建脚本和 Keil 各 Flash 链接范围已同步限制 |
| `0x0800DC00`～`0x0800E3FF` | 新版日志，第55、56页，共2KB |
| `0x0800E400`～`0x0800EBFF` | 已验证的口令配置区，保留 |
| `0x0800EC00`～`0x0800F3FF` | 旧图案区，保留 |
| `0x0800F400`～`0x0800FBFF` | 旧格式日志，保留，不自动导入或擦除 |
| `0x0800FC00`～`0x0800FFFF` | 原数字密码区，保留 |

新版初始为空不代表旧日志已丢失。旧格式缺少版本、CRC和独立胁迫字段，因此本轮选择独立区域，不猜测迁移含义。编译脚本同时核对 Keil 的 IROM、链接区域与 HEX 边界。
