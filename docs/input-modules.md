## 模块边界

- `key.c/.h`：矩阵扫描、消抖、键值和物理位置；不再存放密码编辑逻辑。
- `password_input.c/.h`：数字输入缓冲、逐位删除及确认快照。`SavedPwd` 是 RAM 中的已提交输入，不是持久化密码；旧文字显示函数作为兼容接口保留。
- `encoder.c/.h`：方向事件队列、正交解码与溢出检测。
- `dial_sequence.c/.h`：旋钮序列、合法性及通用比较。比较不使用界面指针坐标。
- `input_event.c/.h`：统一输入事件；数字与旋钮输入均使用完整快照提交。
- `password_demo`、`interaction_demo`：测试界面适配器；正式状态机可以替换这些界面调度，复用上述核心模块。

## 输入事件

`InputEvent` 包含 `kind`、`method`、数字输入或旋钮序列。事件种类为 `SUBMITTED`、`CANCELLED`、`FAULT`，空事件为 `NONE`。

`InteractionDemo_Update(key)` 之后，应在同一个主循环周期调用 `InteractionDemo_TakeEvent(&event)`。它取走一个完整快照并清除待取事件。重复按 # 不重复发布同一输入；数字输入编辑后可以重新提交，旋钮输入提交后须清空才能重新输入。取消、清空或新一轮输入不会遗留可用于开锁的旧提交。

三段旋钮序列只是“已完整输入”，不等于认证成功。2026-10-26 修复入口 1 的漏接：提交后通过 `DuressDemo_EvaluateInput` 调用 `Auth_Evaluate`，读取已保存配置，区分普通、胁迫或错误并持久化日志。普通和胁迫均显示 `PASS`；未配置显示 `NO CFG`，需在入口3显式初始化；审计积压不能接收时显示 `BUSY`。不会自动初始化口令。
