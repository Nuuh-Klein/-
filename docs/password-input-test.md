## 立即上板测试

1. 下载并运行，应出现 `INPUT TEST`，第三行提示 `2 Password test`。
2. 按 `2`，进入左侧小九宫格、右侧输入槽的页面。右侧依次提示 `# OK`、`* Del`、`0 Exit`。
3. 按 `1、2、3、4、5、6`，每按一次增加一个星号，最终为 `******`。九宫格保持不变。
4. 按 `*`，应只剩 5 个星号；再按 `8`，恢复 6 个星号。
5. 按 `#`，提示变为 `# Done`，表示 6 位输入已确认。可继续按 `*` 删除并修改，再按 `#` 确认。
6. 按 `0` 返回主页；再按 `2` 进入，应是全空输入槽。

输入未满 6 位就按 `#`，显示 `#Need6`，保留已有内容。输入已满后继续按数字，显示 `# Full`，不会覆盖最后一位。空输入按 `*` 无副作用。A/B/C/D 不参与测试。

本轮 `# Done` 仅表示输入长度合格并将输入复制到 RAM 中的确认缓冲区，不表示密码校验通过。测试不设置或保存实际密码，不修改数字密码、图案和审计日志 Flash 区，也不执行开锁；初始化保持舵机闭锁、蜂鸣器静音和两灯熄灭。

## 代码入口与检查

- `basic/user/main.c`：测试初始化及键盘轮询入口。
- `basic/user/password_demo.c/.h`：主页进入、逐位输入、确认、退出。
- `basic/hardware/key.c`：复用原密码输入缓冲区，`*` 改为删除一位，`#` 的键码使用实际映射 15，原先的 D 不再误作确认。
- `basic/hardware/pattern_view.c/.h`：复用 OLED 帧缓存和小九宫格，增加普通密码的星号显示函数。
