## 烧录与接线

- 工程：`basic/led.uvprojx`。
- Keil 下载文件：`basic/Objects/led.axf`；HEX 为 `basic/Objects/led.hex`。
- 同内容固件：`basic/build/locking.hex`；`locking.manifest.txt` 首行标明 dial R3/L2/R4 (# submits, PB10 unused)。
- 编码器 A/CH1 接 PB0，B/CH2 接 PB1。PB10 按压开关可以不接；当前入口不初始化或读取它。
- 当前入口不启用 TIM3，确认键沿用矩阵键盘消抖；舵机仍使用 TIM2/PA0，没有新增 GPIO。

## 先核对实物方向与一格计数

1. 下载运行，主页显示 `INPUT TEST`，`1 Dial test`，`2 Password test`，`R3 L2 R4`。
2. 按键盘 `1`。左侧是转盘指针，右侧三段开始时为 `1:---`、`2:---`、`3:---`。
3. 缓慢顺时针转一个机械卡点，预期为 `1:R01`，指针顺时针前进一格。
4. 按键盘 `*` 清空，再逆时针转一格，预期为 `1:L01`。

方向与卡点需用实物确认。若顺时针显示 L，或必须转两个卡点才加 1，请反馈实际现象，不必为了测试换线。参数集中在 `basic/user/config.h`：

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| `ENCODER_DIRECTION` | `1` | 顺时针显示 L 时改成 `-1` |
| `ENCODER_EDGES_PER_STEP` | `4` | 完整正交周期作为一格；半周期卡点型使用 `2` |
| `ENCODER_KEY_DEBOUNCE_MS` | `25` | 仅供保留的 PB10 驱动单独测试，当前入口不使用 |

方向和格数核对一致后再进行完整序列测试。

## 固定序列验证

1. 按 `*` 清空。
2. 顺时针转 **3 格**，第一行显示 `1:R03`。
3. 逆时针转 **2 格**。反转自动开始第二段，显示 `2:L02`。
4. 再顺时针转 **4 格**，第三行显示 `3:R04`。
5. **按键盘 `#`**，右下角应显示 `PASS`。本轮只是匹配成功提示，不开锁。
6. 结果保持显示。按 `*` 清空重试，按 `0` 返回主页。

一段内停顿不会结束本段，只有反转才分段。过冲不能通过反转撤销，因为反转代表新的一段；请按 `*` 从头开始。

## 按键和提示

| 页面 | 操作 | 结果 |
| --- | --- | --- |
| 主页 | 键盘 `1` | 旋钮转盘测试 |
| 主页 | 键盘 `2` | 保留的普通密码输入测试 |
| 旋钮页 | 正反旋转 | 同方向累加，反转自动分段 |
| 旋钮页 | 键盘 `#` | 提交三段序列；正确 `PASS`，错误 `NO MATCH` |
| 旋钮页 | 键盘 `*` | 清空全部记录，指针回到起点 |
| 旋钮页 | 键盘 `0` | 退出至主页 |
| 旋钮页 | PB10 按压、其他键盘键 | 不提交、不改变旋钮序列 |

左下角 `*X 0Out` 表示 * 清空、0 退出。`# OK` 表示按键盘 # 确认；`Need 3` 表示不足三段，输入保留。超过三段或单段超过 99 格会显示 `Long! *X`，须清空重试。事件缓存溢出显示 `Lost! *X`，不会接受可能缺失的序列。

结果显示后继续旋转或再按 # 不会反复验证，按 * 才开始新一轮。可先输入错误序列核对 `NO MATCH`，再清空做正确序列。

## 普通密码界面回归

按 `0` 回主页，再按 `2`。仍为左侧静态九宫格、右侧六个密码槽，输入 `1～9` 显示星号；`#` 确认、`*` 只删除一位、`0` 退出。此模式的旋钮动作会被丢弃，不混入下一次旋钮测试。

## 模块与自动检查

- `basic/hardware/encoder.c/.h`：正交解码、方向事件队列、溢出检测、按压消抖。
- `basic/hardware/dial_sequence.c/.h`：同向累加、反转分段、指针位置、固定序列比较。
- `basic/hardware/dial_view.c/.h`：OLED 转盘、三段计数与结果。
- `basic/user/interaction_demo.c/.h`：测试菜单、模式隔离、清空和返回。
- `basic/user/main.c`：硬件初始化与轮询入口。
