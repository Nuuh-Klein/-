# 创意 1 图形密码硬件验证

> 此文为此前按键图案原型的验证记录，已退出当前主程序。用户决定后续将该创意改用旋钮；目前先运行[普通密码输入界面测试](password-input-test.md)。下述按键图案操作不适用于当前下载文件。

本轮只实现创意 1，等待上板验证。规则为逐键连线，不自动补中间点；图案含 4～9 个不重复节点。设置入口按用户确认先直接开放，输入两遍一致才保存。创意 3 尚未开始。

## 烧录与接线

- Keil 工程：`basic/led.uvprojx`。
- 使用本轮生成的 `basic/Objects/led.axf` 下载；HEX 为 `basic/Objects/led.hex`。
- 相同固件另存于 `basic/build/locking.axf`、`locking.hex`；`locking.manifest.txt` 记录 HEX 及源文件散列。
- 继续使用已验证的接线：键盘行 PA8/PB15/PB14/PB13，列 PA9/PA10/PA11/PA12；OLED PB8/PB9；舵机 PA0；蜂鸣器 PB12；红灯 PC14，绿灯 PC15。
- 本轮不需要新增接线，指纹、编码器不参与演示流程。
- 固件只读写独立图案区，不初始化数字密码和日志区。为验证掉电保存，设置成功后直接复位或断电重启；整片擦除会删除存储的图案。

## 按键与屏幕

| 所在页面 | 按键 | 行为 |
| --- | --- | --- |
| 主页 `PATTERN DEMO` | `1` | 进入图案验证；未设置则提示 `NO PATTERN` |
| 主页 | `2` | 进入图案设置第一遍 `SET 1/2` |
| 图案输入页 | `1`～`9` | 选择对应节点并画线；重复节点提示 `Used!`，不会加入序列 |
| 图案输入页 | `#` | 提交；不足 4 点提示 `Min 4!`，不计错误次数 |
| 图案输入页 | `*` | 清空本遍输入 |
| 图案输入页 | `0` | 放弃设置/输入，返回主页 |
| 任意页面 | `A/B/C/D` | 不参与本轮操作 |

OLED 左侧九宫格与键盘的 1～9 相同排列，选中节点反白，右侧 `N:4/9` 表示已选 4 点。`#OK *X` 表示 # 提交、* 清空，`0 Back` 表示返回。提示页约 1.2 秒后自动继续。

## 先完成这一组实物验收

1. **启动**：下载并运行，出现 `PATTERN DEMO`，舵机处于闭锁位置，两灯熄灭，蜂鸣器静音。首次使用通常显示 `No pattern saved`；若已有有效图案则显示 `Saved / NO ADMIN`。
2. **设置**：主页按 `2`，依次按 **1、3、9、7、#**。进入 `SET 2/2` 后，再按 **1、3、9、7、#**，应提示 `PATTERN SAVED`，随后返回主页。
3. **图形检查**：输入上述图案时，只选中四个角。2、6、8 不应被选中，虽然连线会经过它们的坐标。节点计数最终为 `N:4/9`。
4. **开锁**：主页按 `1`，再按 **1、3、9、7、#**。应显示 `UNLOCKED`、绿灯亮、蜂鸣器短响，舵机开锁；约 **3 秒**后自动回锁并返回主页。
5. **掉电保存**：不重新烧录，直接断电再上电。按 `1`，输入同一图案，应仍可开锁。

先反馈以上五步的实际结果，确认基础闭环后再继续下面的边界检查。若有问题，记录停在哪一步、OLED 原文，以及舵机/指示灯/蜂鸣器的现象。

## 边界与失败路径

| 检查 | 操作 | 预期 |
| --- | --- | --- |
| 重复节点 | 图案页输入 `1、3、1` | `Used!`，计数仍为 2 |
| 最短长度 | 清空后输入 `1、2、3、#` | `Min 4!`，留在输入页，不报警、不计一次密码错误 |
| 清空与返回 | 按 `*`；再按 `0` | 先清空本遍轨迹，再返回主页 |
| 设置不一致 | 第一遍 `1、3、9、7、#`；第二遍 `1、2、3、4、#` | `NOT SAME`，两遍重新开始；原来保存的图案仍有效 |
| 三次错误 | 对已保存的 `1397`，连续提交三次 `1、2、3、4、#`，每次等待提示结束 | 前两次提示剩余次数；第三次 `LOCKED`，红灯亮，蜂鸣器前约 2 秒间歇报警 |
| 锁定计时 | `LOCKED` 后尝试 `0`、`2`、正确图案等 | 不能跳过锁定；屏幕从 30 秒递减，约 30 秒后返回主页，红灯与蜂鸣器关闭 |
| 最大长度 | 设置时输入 `1、2、3、4、5、6、7、8、9、#` 两遍 | 允许保存 9 点；验证顺序必须相同 |
| 修改与恢复 | 改成新图案，再断电重启 | 新图案生效；旧图案不匹配 |

错误次数在成功开锁或 30 秒锁定结束后清零；清空输入、返回主页不会清零。本演示版错误计数和锁定状态保存在 RAM 中，复位会重置。图案设置入口按本轮约定直接开放，界面显示 `NO ADMIN`；后续接入管理员验证时再收紧入口。

## 模块与存储布局

| 模块 | 文件 | 内容 |
| --- | --- | --- |
| 图案规则 | `basic/hardware/pattern.c/.h` | 追加节点、去重、长度和顺序比较 |
| 图形显示 | `basic/hardware/pattern_view.c/.h`、`OLED.c/.h` | 1024 字节帧缓存、画点连线、文字与九宫格 |
| 图案存储 | `basic/hardware/pattern_store.c/.h` | 双页追加记录、版本、序号、CRC、数据回读和最后提交标记 |
| 演示状态机 | `basic/user/pattern_app.c/.h`、`main.c` | 设置两遍、验证、提示、开锁、错误锁定 |
| 毫秒计时 | `basic/system/timebase.c/.h` | TIM3 每毫秒中断，避开现有 SysTick 使用者 |

| 地址范围 | 用途 |
| --- | --- |
| `0x08000000`～`0x0800EBFF` | 程序区，Keil 与构建脚本均设置边界 |
| `0x0800EC00`～`0x0800F3FF` | 图案双页区，第 59、60 页，每页 1 KB |
| `0x0800F400`～`0x0800FBFF` | 原审计日志区，保留 |
| `0x0800FC00`～`0x0800FFFF` | 原数字密码区，保留 |

图案采用 32 字节定长记录。写满当前页才擦除另一页，提交新记录前保留上一份有效图案；未提交或 CRC 错误的记录不作为新图案加载。如存在更早的有效记录，则加载其中最新一份。全部记录无效时显示 `Store invalid`，可重新设置。只在成功设置时写 Flash，按键、绘图、验证不会反复写图案区。

本轮入口不调用原数字密码、胁迫密码、指纹、编码器和日志业务；这些驱动与已有数据保留。图案开锁暂不写审计记录，待后续统一业务接入时处理。
