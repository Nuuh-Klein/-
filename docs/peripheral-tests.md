# 外设测试操作

当前入口是 `basic/user/main.c`，原密码锁 main 业务代码仍完整保留在注释中。测试固件为 `basic/build/peripheral-test.hex`。数字键 **5** 测试编码器，物理按键 **S14** 分步控制指纹；S14 为现有 4×4 驱动的第四行第二列，键帽为 **0**，不是返回键码 14 的 C 键。

## 基础测试

上电显示 `IO:5=ENC S14=FP`。已有控制保持不变：S1 红灯亮，S2 绿灯亮，S3 舵机到约 90°，S4 蜂鸣器响 50 ms。S1～S4 仍为现有 4×4 驱动第一行的 1、2、3、A。灯和舵机保持触发后的状态。

在任一模式按 `*` 返回此界面；数字 5 进入编码器模式，S14 进入指纹流程。指纹采集/等待移开过程中也可按 `*` 取消；串口命令本身需要等本次应答或超时后才处理按键。原指纹数字 6 入口及 1/2 录入/识别快捷键已由 S14 分步流程替代。

## 测试 1：旋转编码器与 PB10

按数字 **5**，OLED 显示：

```text
1 ENCODER TEST
Pos:+00000  Dir:
PB10:UP   N:0000
5:0 S14:FP *:IO
```

- 正反向转动编码器，`Pos` 应增减，`Dir` 显示最近一次变化的 `+` 或 `-`。正负方向取决于 A/B 相接线。
- 按下 PB10 编码器按键，`PB10` 显示 `DOWN`，`N` 增加一次；松手恢复 `UP`。长按不连续计数，按下与释放均在主循环消抖，中断中不延时。
- 再按 5 清零旋转位置和按键次数；S14 切换指纹，`*` 返回基础测试。

编码器接线保持 PB0/PB1 两相、PB10 按键。旋转差值由 EXTI 中断累计并原子读出；显示范围限制为 ±99999，按键次数在 9999 后回到 0。

## 测试 2：指纹录入、保存、识别

1. **第一次按 S14：进入录入准备。** 初始化 USART2，验证配置中的通信密码，读取模块容量和已存模板数量。成功显示 `FP ENROLL READY`、`Used:已用/容量` 和 `Place finger`。此时尚未采集、尚未写入模板。
2. 放好手指，**第二次按 S14：执行录入。** 程序读取索引表，选择第一个空闲 ID。根据 OLED 提示完成 `Place finger #1` → `Lift finger` → `Same finger #2`。AS608 现有录入流程需要两次采样，请按提示移开并放回同一根手指，不需要额外按 S14。
3. 录入完成显示 `FINGER SAVED`、保存 `ID` 和模板数量 `N`；失败显示具体错误，按 S14 重试录入。不会自动开始识别。
4. **第三次按 S14：进入检测准备。** OLED 显示 `FP VERIFY READY` 和 `Place finger`；此时不采集、不比对。放好待检测手指。
5. **第四次按 S14：执行采集和比对。** 成功显示 `MATCH OK`、匹配 ID 和 `Score`；未录入手指显示 `NO MATCH`。

完成一次比对后，再按 S14 回到检测准备，再按一次 S14 执行下一次比对。每次 S14 必须松开后重新按下，长按不会连续推进阶段。数字 5 切到编码器，`*` 返回基础测试；退出后重新按 S14 会从录入准备开始。指纹模板保存在模块内，不随退出或重启删除；重新上电进入准备界面的 `Used` 可核对已存数量。

录入或识别等待手指时，`*` 可取消；每个等待阶段有超时保护。通信失败保留当前操作阶段，以便 S14 重试；连接未成功时，S14 重新尝试连接。

## 指纹错误反馈

错误界面包含十六进制 `Code` 与 `Cmd`，用于定位模块应答及最后命令。

| 提示 | 含义/操作 |
| --- | --- |
| UART TIMEOUT | 检查模块供电、共地、57600 波特率，PA2→模块 RX、PA3←模块 TX；按 S14 重试 |
| PASSWORD ERROR | `config.h` 的 AS608_PASSWORD 与模块现有通信密码不一致；程序不会修改模块密码 |
| FINGER TIMEOUT | 长时间未放置或未移开手指，重试本次操作 |
| NO MATCH | 当前采集成功，但未在已存库中匹配 |
| USE SAME FINGER | 两次录入特征无法合并，使用同一根手指重新录入 |
| LIBRARY FULL | 索引表没有空闲 ID，不再写入 |
| RETRY FINGER | 图像、特征或其他协议错误；结合 Code/Cmd 排查 |

不把可选灯控命令的成败当作指纹通信成功依据。搜索范围来自模块实际容量，索引 ACK 共 44 字节，因此接收缓冲区已由 32 扩大至 64 字节。参数读取和索引位图格式参考 [Adafruit 官方兼容协议实现](https://github.com/adafruit/Adafruit_CircuitPython_Fingerprint/blob/main/adafruit_fingerprint.py)。若具体模块固件不支持索引查询，界面会报告原始错误码，停止该次录入。

## 已完成的软件验证

- 主机模拟运行实际编码器驱动及 main 模式函数：正反转、抖动、非法跳变、PB10 中断消抖、OLED 字段边界、S14 四次按压流程、准备阶段不采集、重复检测、错误重试和取消。
- 模拟 UART 运行实际 AS608 驱动：参数与模板数量、跨页空闲 ID、两次采集与保存、按容量搜索、异常报文、超时、库满及保存前取消。
- 原键盘、PWM、蜂鸣器及 LED 回归模拟通过。
- Keil ARMCC/ARMASM/ARMLINK 编译链接整个工程，目标限制为 64 KB Flash、20 KB RAM。

模拟持久存储仅验证软件调用逻辑；实际识别效果、旋转方向及掉电保存仍须按以上步骤在硬件上验证。
